# PulseMarkets — Real-Time Stock & Crypto Market Dashboard

A modern web application that delivers **live financial market data** and
**AI-driven short-term price predictions** for top global stocks and the
leading cryptocurrencies.

![stack](https://img.shields.io/badge/Next.js-16-black) ![stack](https://img.shields.io/badge/React-19-blue) ![stack](https://img.shields.io/badge/Recharts-3-red)

## Features

- **Live market data** — real-time crypto prices via the public CoinGecko API
  and a realistic simulated stock feed (configurable to a real provider).
  Auto-refreshes every 8 seconds.
- **Interactive charts** — price history with time-range filters
  (1D / 1W / 1M / 3M / 1Y / All-Time), zoom, crosshair tooltips.
- **AI price predictions** — 1h / 24h / 7d forecasts per asset with confidence
  scores, support/resistance levels and rationale. Powered by an LLM on the
  Antseed network (`agnes-3.0-flash` primary, `deepseek-v4.1` fallback) with a
  self-contained heuristic fallback if the proxy is unreachable.
- **Technical indicators** — RSI, MACD, Bollinger Bands, SMA-20/50, volume.
- **Watchlist / favorites** — saved per user in `localStorage`.
- **Search** — keyboard-navigable asset search over stocks and crypto.
- **Dark / light mode** — dark theme default, toggle persisted.

## Tech Stack

- **Frontend:** React 19 + Next.js 16 (App Router), Tailwind CSS v4
- **Charts:** Recharts
- **Real-time data:** CoinGecko (crypto) + pluggable stock API + simulation
- **AI predictions:** Antseed buyer proxy (OpenAI-compatible endpoint) with
  heuristic fallback

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

### AI Predictions (Antseed)

The prediction engine calls the Antseed buyer proxy at
`http://127.0.0.1:8377/v1` (OpenAI-compatible). Make sure your **AI VPN desktop
app** is running, or start the CLI proxy:

```bash
export ANTSEED_IDENTITY_HEX=<your-private-key-hex>
antseed buyer start
```

Models used (override in `.env`):

| Variable | Default |
| --- | --- |
| `AI_API_BASE` | `http://127.0.0.1:8377/v1` |
| `AI_API_KEY` | the key provided |
| `AI_PRIMARY_MODEL` | `agnes-3.0-flash` |
| `AI_FALLBACK_MODEL` | `deepseek-v4.1` |

Copy `.env.example` → `.env.local` and adjust as needed.
If the proxy is not running, predictions fall back to a built-in
momentum/volatility model so the dashboard stays fully functional.

### Stock data

Crypto uses the free public CoinGecko API (no key required). Stocks default to
a realistic simulated feed so the app works immediately. To use real stock
data, set `STOCK_API_KEY` and `STOCK_API_BASE` (e.g. Alpha Vantage) in
`.env.local`. See `.env.example`.

> **Note:** Real-time stock APIs often require a paid subscription key. The
> simulated feed preserves the full experience and can be swapped seamlessly.

## API Routes

- `GET /api/assets` — all assets (stocks + crypto) with live prices
- `GET /api/asset?id=<id>&range=1W` — asset detail + candles + indicators
- `GET /api/predict?id=<id>` — AI prediction for an asset (cached 90s)

```
  coinGecko.ts             # Crypto data source
  stocks.ts                # Stock feed (real or simulated)

  aggregator.ts            # Combines sources + candles
  format.ts, types.ts
```
